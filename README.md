О проекте.
Мобильное приложение для создания и управления личной онлайн-библиотекой. Интегрируется с OpenLibrary Api для поиска книг, имеет возможность добавлять книги в избранное по категориям, отслеживать прогресс чтения, вести историю просмотров. На текущем этапе реализован просмотр книг по категориям, поиск с пагинацией, оффлайн-режим.

Функции приложения:
1.Поиск книг по названию и автору через OpenLibrary Api
2.Персональная книжная полка с системой статусов: хочу прочитать, читаю, прочитано
3.История просмотров – автоматическое сохрание просмотренных книг
4.Детальная информация – экран с обложкой, данными о конкретной книге
5.Поделиться книгой - возможность поделиться информацией о книге
6.Система напоминаний - установка будильника для категории книг "Хочу прочитать" с выбором даты и времени напоминания с помощью BroadcatReceiver и AlarmManager для точных напоминаний

Технологии:
-	UI – JetpackCompose
-	Архитектура – MVVM
-	DI – Dagger
-	БД – Room
-	Сеть – Retrofit
-	Асинхронность – Coroutines/StateFlow
-	Навигация – Compose Navigation
-	Coil для изображений
-	Уведомления: AlarmManager + BroadcastReceiver

Экраны:
HomeScreen:
Функционал: поле для поиска по OpenLibrary Api
Табы категорий для книг для быстрого переключения по категориям книг
LazyColumn с карточками книг BookCard с реализованной пагинацией. При достижении конца списка происходит догрузка книг. Реализованы индикаторы загрузки. Сохранение позиции скролла.
Реализована работа в оффлайн-режиме. При отсутствии сети показываются кэшированные данные.
Градиентный фон в фиолетово-серой цветовой схеме

BookDetailScreen: Детали книги
  - Обложка с тенью и анимацией
  - Описание с поддержкой Spannable (форматированный текст)
  - Авторы и метаданные
  - Расширяемые списки тегов, жанров и персонажей
  - Интерактивная система книжной полки
  - Панель инструментов (FAB):
    - Поделиться книгой
    - Скачать обложку
    - Установить напоминание (для статуса "Хочу прочитать")
- Нативные диалоги выбора даты и времени для напоминаний

MyBookShelfScreen: Книжная полка
TabLayout  с категориями (Хочу прочитать, Читаю, Прочитано)
Визуальное отображение пустых состояний
Отображение BookCard книг, находящихся в категориях

HistoryScreen: История просмотров. 
- История просмотров книг
- Автоматическое управление кэшем
- Очистка истории

NotificationsScreen: Экран уведомлений
- Показываются актуальные уведомления, которые будут показаны пользователю в будущем времени
- Проверка актуальности уведомления
- Возможность отменить или редактировать уведомление

SettingsScreen: Экран настроек
- Выбор темы: светлая, темная или системная (в зависимости от настроек устройства)
- При выборе темы показывается круговая анимация
- Выбор стартового экрана приложения
- Switch включения/отключения уведомлений от приложения

DI реализован с помощью dagger. ViewModel создается с помощью фабрики для корректного управления состоянием и жизненным циклом. Разделение на модули: DataBaseModule, NetworkModule, RepositoryModule, ViewModelModule

Приложение имеет одну Activity с BottomBar с 3 пунктами. На экране деталей BottomBar скрыт. Compose Navigation с передачей параметров через аргументы.

Данные: 
Получение данных: ViewModel получает данные из репозитория. Репозиторий делает сетевой запрос, произодится маппинг полученных данных, сохранение в базу с определением категории. Данные отправляются во ViewModel, при отсутствии сети репозиторий возвращает данные из кэша.

Работа с разрешениями:
Android 13+: POST_NOTIFICATIONS, READ_MEDIA_IMAGES
Android 12+: SCHEDULE_EXACT_ALARM
Legacy: WRITE_EXTERNAL_STORAGE

Работа с будильниками:
AlarmManager для точных напоминаний
BroadcastReceiver для обработки событий
Кастомные уведомления с действиями
Учет разных версий Android
